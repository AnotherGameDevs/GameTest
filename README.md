# DIG & RUN! — Milestone 1 (Base Loop)

## Play it
1. Open `Build/DigAndRun.rbxlx` in Roblox Studio.
2. Press **Play** (F5). Nothing else to set up — the map, remotes, UI and shovels are all generated by code.

(Optional) To save progress in Studio: Game Settings → Security → *Enable Studio Access to API Services*, and publish the place once.

## Developing
Source of truth is the Rojo project (`default.project.json`, `src/`). Rebuild the place with:
`rojo build default.project.json -o Build/DigAndRun.rbxlx`  — or `rojo serve` for live sync.

## Layout
- `src/shared`  Config (all balance), Defs (tools/backpacks/treasure/rarity), Grid, Remotes, Util
- `src/server`  Services: Data, Site, Dig, Loot, Inventory, Economy, Equipment, State, WorldBuilder, RateLimiter, Analytics
- `src/client`  Controllers: State, Dig (input), Effects, Audio, UI, Interaction
