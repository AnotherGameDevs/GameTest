# DIG & RUN!

Dig a block mine, sell treasure, upgrade tools, carry important artifacts home, collect them. **Release candidate for
testing — not yet run in Roblox Studio** (see `docs/RELEASE_CANDIDATE.md`).

## Play it
1. Open `Build/DigAndRun.rbxlx` in Roblox Studio and press **Play** (F5). The map, remotes, UI and tools are all generated by
   code; nothing else to set up. Controls: hold left mouse to dig, **J** journal, **P** menu, **R** to camp, **X** place an
   artifact, **G** throw dynamite, **Alt** free cursor, **V** camera.
2. To test saving: publish a **test** place, enable *Studio Access to API Services* on it (never on production), and play.

## Developing
Source of truth is the Rojo project (`default.project.json`, `src/`). Rebuild:
`rojo build default.project.json -o Build/DigAndRun.rbxlx` — or `rojo serve` for live sync.

## Checks (no Roblox needed)
* `LUAU=/path/to/luau bash tests/run_all.sh` — artifact state machine, migrations, settings, tool assembly, ground plan,
  camp layout, collection/guide/mine-shift/progression data.
* `rojo sourcemap default.project.json --output sourcemap.json` then
  `luau-lsp analyze --definitions=globalTypes.d.luau --sourcemap=sourcemap.json src` — type check.
* `python3 tools/economy_sim.py` — the (analytic, not measured) economy model.

- `src/shared`  Config (all balance), Defs, Grid, GroundPlan, models (Tool/Treasure/Pack), pure specs (Collection, Guide, Shift, Settings)
- `src/server`  Services: Data (session lock), Site, Dig, Loot, Inventory, Economy, Equipment, Artifact, Collection, MineShift, Elevator, World*
- `src/client`  Controllers: Camera, Viewmodel, Dig, Effects, Audio, UI, Shop, PauseMenu, CollectionUI, CampShelf, Guide
